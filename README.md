# 이주연 | AI·백엔드 개발자 포트폴리오

RAG 챗봇과 데이터 파이프라인을 만드는 개발자 이주연의 포트폴리오 사이트입니다.

🔗 **사이트**: https://clinquant-syrniki-eb036e.netlify.app

🐙 **GitHub**: https://github.com/jynlee

## 소개

안녕하세요, AI·백엔드 개발자 이주연입니다.

LLM과 RAG 같은 생성형 AI 기술에 관심을 두고, 문서를 검색해 근거와 함께 답하는 챗봇을 만들고 있습니다. 법령 데이터 수집부터 검색, 답변 생성까지 서비스가 동작하는 전 과정을 직접 다뤄 왔습니다.

막히면 다른 길을 찾아 계속 시도하고, 바로 실행해 보는 습관을 만들고 있습니다. 현재는 AI핀테크 융합과에서 데이터 파이프라인과 모델 실습을 이어가며, 만든 것을 서비스로 연결하는 개발자를 목표로 하고 있습니다.

## 폴더 구조

- `index.html`: 페이지 구조
- `css/style.css`: 스타일
- `js/main.js`: 화면 렌더링, 테마·언어 전환
- `js/data.js`: 프로젝트·기술 등 언어와 무관한 데이터
- `js/i18n.js`, `js/i18n/`: 다국어 엔진과 ko, en, zh, ja 번역 파일
- `assets/`: 프로필·프로젝트 이미지

## 수정 방법

- 문구: `js/i18n/` 안의 언어별 파일
